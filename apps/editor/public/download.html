Use OpenTempl

OpenTempl runs in your browser and works offline once it has loaded. The desktop app for Mac, Windows and Linux is the same editor in its own window.

Updated November 2026

Web app

Open https://opentempl.org. Chrome and Edge may offer to install it as an app, which then opens without a browser window. Your designs are saved on your device. Clear the site data and they go with it, so save a file for anything you want to keep.

Desktop app

Version 0.1.0. Every build is listed with its checksum on the release page.

  • macOS, Apple silicon (M1 and newer)
  • macOS, Intel
  • Windows 10 and 11
  • Linux, AppImage or .deb

The first builds are not code signed. On macOS, right click the app and choose Open the first time. On Windows, choose More info, then Run anyway.

System

A recent version of Chrome, Edge, Firefox or Safari for the web app. Designs with many large photos use a lot of memory; close other heavy tabs for big posters. Background removal downloads a small model the first time you use it.

Questions

Is it free?

Yes. There is no paid plan, trial or watermark. The licence is MIT.

Do I need an account?

No.

Does it work offline?

Yes, after it has loaded once. Fonts you have not used before, icon search, stock photos and live sessions need a connection. See the offline page.

Where are my files?

On your device. Export the editable OpenTempl file to keep a copy or move a design to another computer.

OpenTempl

OpenTempl is a free, open source (MIT) design app for posters, social media posts and slides, with 337 templates, that works offline and needs no account.
