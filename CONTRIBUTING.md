# Contributing

Thanks for wanting to help. Bug reports, fixes and small focused changes are all welcome. For anything large, open an issue first so we can agree on the shape before you spend the time.

## Setup

Requires Node.js 22 or newer.

```sh
npm install
npm run dev        # the editor on http://localhost:5181
```

## Checks

```sh
npm run typecheck
npm test           # unit tests (vitest)
npm run build
```

`qa/` holds Playwright scripts that drive the dev server like a person would, for example `node qa/pdf-test.mjs`. They need `npm install --no-save playwright` and a Chrome install. Run the dev server first.

## Layout

[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) explains how the pieces fit. The short version: the editor is in `apps/editor`, the sharing relay in `sync/`, the anonymous counter in `stats/`, and the static pages for opentempl.org are generated by `seo/build.mjs`.

## Templates

Templates are code. Each style has a source file in `apps/editor/templates/vibes/`, written with the helpers in `apps/editor/templates/kit.mjs`.

```sh
node scripts/build-templates.mjs <vibe>    # validate and build
node qa/tpl-render-server.mjs              # in a second terminal
node qa/tpl-shot.mjs <vibe> [id ...]       # render PNGs to look at
```

[apps/editor/templates/BUILDING.md](apps/editor/templates/BUILDING.md) covers the kit, the formats, the image library and what makes a template good. A new template needs a unique id, plain sample copy and a layout that survives swapped words and photos.

## Desktop builds

```sh
npm run build
cp -R dist/app apps/desktop/app
cd apps/desktop && npm install && npx electron-builder --mac dmg
```

## Code style

- TypeScript, strict. Small modules with one job.
- Comments explain why, never what.
- Names say what things are. No abbreviations beyond the common ones.
- Validate at the edges (files, network, imports) and trust internal calls.
- Every edit to a design goes through the `DesignDoc` transaction, so undo, saving and sharing stay in step.
- Pure logic gets a unit test in `apps/editor/test`.
- Copy in the app and the docs is plain English: no em dashes, no hyphenated compound words, no exclamation marks.
- `.editorconfig` sets indentation and line endings.

## Pull requests

- Keep it focused. One change per pull request.
- `npm run typecheck` and `npm test` pass.
- You tried the change in a browser, not only in tests.
- New behaviour has a test where a test makes sense.
- Anything that sends data off the device is called out in the description and added to [docs/PRIVACY.md](docs/PRIVACY.md).
